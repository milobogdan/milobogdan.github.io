Privacy policy

Kistl backup tool · last updated 25 October 2026

Kistl is a personal backup tool that runs on a Windows PC. This policy explains what happens to data, including Google user data, when Kistl is used.

Summary

Kistl collects no personal data. It has no servers, no accounts, no analytics and no advertising. Everything it does happens on the user's own PC and in the user's own storage.

Google user data Kistl accesses

  • Kistl requests only the Google Drive scope https://www.googleapis.com/auth/drive.file. With it, Kistl can create files and folders in the user's Google Drive and read, change or delete only those files and folders that Kistl itself created. It cannot see any other file in the user's Drive.
  • To show how much storage is left, Kistl reads the storage quota and the account's email address from the Google Drive API. These are shown on the user's screen only and are not stored or sent anywhere.

How Kistl uses that data

  • Kistl uploads backup copies of folders the user chooses, downloads them again when the user restores or checks a backup, and removes old backup copies according to the user's retention settings.
  • Before any file leaves the PC, Kistl encrypts it with AES-256 using a key that is created and kept on the user's PC. File contents and file names stored in Google Drive are therefore unreadable to Google and to anyone else without that key.
  • Google user data is used for nothing else: not for advertising, profiling, analytics or training any kind of model.

Storage

  • The Google sign-in token and the encryption key are stored only on the user's PC, in Windows Credential Manager.
  • Backups are stored only in the user's own Google Drive (and on the user's own drives or NAS, if configured).

Sharing

Kistl does not share, sell or transfer any data to anyone. Data travels only directly between the user's PC and Google, over an encrypted (HTTPS) connection.

Deleting data and revoking access

  • "Sign out" in Kistl revokes its access at Google and removes the sign-in token from the PC.
  • Access can also be removed at any time in the Google Account under Third-party apps & services.
  • Backups in Google Drive can be deleted by the user in Google Drive at any time.

Contact

Questions about this policy can be sent to the support email address shown on Google's sign-in screen for Kistl.
