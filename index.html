Kistl

Your files, safely tucked away

What Kistl is

Kistl is a small backup tool for Windows, made for personal use. It copies the folders its user chooses to a local or external drive, a NAS on the home network, and optionally to that user's own Google Drive. "Kistl" is Austrian and Bavarian for a small chest.

How it uses Google Drive

  • Files are encrypted on the user's PC (AES-256) before anything is uploaded. Google only stores unreadable data.
  • Kistl asks only for the drive.file permission: it can see only the files and folders it created itself, never anything else in the user's Drive.
  • There is no Kistl server. The app talks directly from the user's PC to Google.

Privacy

Kistl collects no data about anyone. Read the privacy policy.
